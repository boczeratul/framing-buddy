# Framing Buddy · 取景規劃

攝影師的拍攝規劃工具：選擇世界上任何地點，預覽不同鏡頭焦段、角度、高度與時間光線下的畫面，並確認地標會不會入鏡、會不會被擋住。起始點是台北中正紀念堂自由廣場。

## 啟動

```bash
cp .env.example .env.local   # 填入 Google Maps Platform 金鑰
npm install
npm run dev                  # http://localhost:5173
npm run build                # 型別檢查＋打包到 dist/
```

金鑰需要啟用：Maps JavaScript API、Places API (New)、Map Tiles API（實景 3D 圖磚）。地形高程透過 Maps JavaScript API 的 Elevation 服務取得。也可以在介面的「場景載入 → 金鑰」直接貼上金鑰（只存在該瀏覽器）。

> 這是純前端應用，金鑰一定會出現在瀏覽器端。請在 Google Cloud Console 為金鑰設定 **HTTP referrer 限制**（例如 `http://localhost:5173/*` 與正式網域）與 **API 限制**。

沒有金鑰或金鑰無效時會自動改用備援：左側地圖改為俯視圖、近景改用 OpenStreetMap 精細建物、地形改為平面。

## 場景如何載入

依相機位置、朝向、視角與可視範圍動態載入，分兩種精細度：

| 範圍 | 內容 | 資料來源 |
| --- | --- | --- |
| **近景**（預設 1 km 內，可調 200 m–3 km） | 實景 3D 模型（建物、樹木、地形） | Google Photorealistic 3D Tiles |
| | 備援（沒有 Google 圖磚時）：建物依樓層與高度擠出，含斜屋頂、圓頂、樹木、綠地、水域 | OpenStreetMap（Overpass API） |
| **遠景**（到可視範圍，預設 6 km，可調 1–20 km） | 高樓（≥25 m）依高度擠出、窗格立面、夜間窗燈；高塔收分 | OpenStreetMap（OpenFreeMap 向量圖磚） |
| | 地標手工模型：中正紀念堂園區、台北 101 | 程序化建模 |
| | 地形與遠山 | Google Elevation |

- 遠景以約 2 km 見方的圖磚為單位載入：視野方向內、較近的優先，相機身旁 2 km 內不分方向都載入，離開範圍的會釋放。
- 近／遠景交界在 shader 中依「與相機的水平距離」精準裁切，走動時邊界跟著移動。
- 選擇距離原點 2.5 km 以上的地點時，會以新地點為原點重建整個場景（避免浮點誤差），時區也會自動切換。

## 介面

左側是**控制區**，右側是**取景結果**。

| 區塊 | 內容 |
| --- | --- |
| 地圖 | Google 地圖：上方搜尋任何地點；點一下移動、拖曳相機或橘色把手、Shift＋點一下朝該點對準；顯示視角扇形、近景（綠）與遠景（白）範圍、太陽／月亮／目標方向線 |
| 俯視／立體 | 以場景本身渲染的俯視圖（含陰影）與繞相機旋轉的 3D 視角（含視錐） |
| 位置 | 快速位置（中正紀念堂各點、象山、巴黎、東京、紐約、香港）、輸入經緯度、我的位置、東西／南北微調 |
| 高度 | 離站立面的高度；勾選「站在地面／屋頂／台階上」時自動貼合（實景模型也適用），取消則為空拍高度 |
| 方向 | 方位角、俯仰、水平；目標下拉選單（地標、範圍內有名稱的高樓與高塔）＋對準；對準太陽、月亮 |
| 鏡頭 | 全片幅等效焦段 8–1200 mm、畫面比例（從 36×24 mm 裁切）、橫幅／直幅 |
| 光線 | 日期與**拍攝地點當地時間**；跳到日出、金色時刻、正午、日落、藍色時刻；太陽、月亮位置與月相；雲量、能見度、曝光補償 |
| 場景載入 | 遠景範圍、近景半徑、是否使用 Google 實景圖磚、實景模型是否套用模擬日照、載入狀態、金鑰 |
| 顯示與分享 | 構圖輔助線、複製分享連結（地點與所有設定都在 URL 裡）、下載畫面 PNG |

取景器上可以拖曳轉動鏡頭、滾輪變焦。鍵盤：W/S 前後、A/D 左右平移、R/F 升降、方向鍵轉向與俯仰、+/- 變焦，按住 Shift 加速。資訊列顯示目前目標的距離、方位、是否入鏡、被遮擋的比例與在畫面中的高度。

## 準確度與限制

- **實景模型的光影**：Google 圖磚的貼圖本身含拍攝當時的光影；開啟「模擬日照」時會再疊上模擬的太陽方向與陰影，適合判斷光線方向，但原有的陰影不會消失。
- **高度對齊**：實景圖磚使用橢球高，會自動與 Google 高程比對校正；在陡坡或密集建築區可能有數公尺誤差。
- **遠景只有高樓**：低於 25 m 的建物不會出現在遠景；遠景建物是依輪廓與高度擠出的方塊，不含細節。
- **OSM 資料完整度**因地區而異；近景備援依賴公共 Overpass 伺服器，忙碌時會較慢或失敗（會自動重試、結果快取 14 天）。
- 天空、曝光與色調是近似值，適合判斷光線方向與大致氛圍，不代表實際色溫與亮度。

## 程式結構

```
src/
  main.ts                 組裝：狀態 → 場景、地圖、HUD、鍵盤、渲染迴圈
  state.ts                拍攝設定（含原點經緯度、時區）與 URL hash 編解碼
  geo.ts                  可移動原點的經緯度 ↔ 場景座標
  time.ts                 時區查詢（離線資料表）與當地時間換算
  lens.ts                 焦段 ↔ 視角、畫面比例
  config.ts, google.ts    金鑰與 Maps JavaScript API 載入
  world/
    World.ts              場景總成：近／遠景協調、站立面、遮擋物、目標
    photoreal.ts          Google 實景 3D 圖磚（近景遮罩、地面校正、受光材質）
    terrain.ts            高程網格地形
    landmarks.ts          地標手工模型圖層（中正紀念堂、台北 101）
    presets.ts            快速位置
    osm/
      OsmLayer.ts         依視野動態載入／釋放圖磚
      vectortiles.ts      遠景：OpenFreeMap 向量圖磚
      overpass.ts         Overpass 佇列與 IndexedDB 快取
      parse.ts            OSM 幾何、高度與屋頂標籤
      mesh.ts             程序化建物、屋頂、樹木、綠地
      named.ts            有名稱的高樓與高塔（可對準的目標）
  scene/
    environment.ts        太陽／月亮、天空、陰影、霧、夜間燈光、自動曝光與測光
    ringmask.ts           近／遠景交界的 shader 裁切
    cks.ts, taipei101.ts  地標程序化模型
    geometry.ts, materials.ts, trees.ts
  views/
    viewfinder.ts         取景器：渲染、構圖線、目標提示、遮擋判定
    googlemap.ts          Google 地圖面板
    mapview.ts            俯視／立體視圖
  ui/panel.ts             控制面板
```
