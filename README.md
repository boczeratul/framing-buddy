# Framing Buddy · 取景規劃

攝影師的拍攝規劃工具：在中正紀念堂園區任意位置，預覽不同鏡頭焦段、角度、高度與時間光線下的畫面，並確認台北 101 會不會入鏡、會不會被擋住。

以 Three.js 程序化建模，不需要任何外部模型或貼圖檔。

## 啟動

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 型別檢查＋打包到 dist/
```

## 介面

左側是**控制區**，右側是**取景結果**。

| 區塊 | 內容 |
| --- | --- |
| 地圖（俯視） | 點一下移動位置、拖曳橘點轉向、Shift＋點一下朝該點對準、滾輪縮放、拖曳空白處平移。扇形是目前的水平視角；另外畫出太陽（☀）、月亮（☾）與台北 101 的方向線 |
| 地圖（立體） | 軌道相機繞著拍攝位置看，並顯示相機視錐；雙擊地面可移動位置 |
| 位置 | 快速位置（牌樓下、正門平台、後方高台看 101…）、東西／南北座標（公尺，原點＝紀念堂中心）、經緯度 |
| 高度 | 離站立面的高度；勾選「站在地面／台階／平台上」時會自動貼合台基、正面 84 級台階與平台高度，取消勾選則以地面起算（空拍） |
| 方向 | 方位角（0°＝北、順時針）、俯仰、水平；一鍵對準 101、紀念堂、太陽、月亮 |
| 鏡頭 | 全片幅等效焦段 8–1200 mm（對數刻度）、常用焦段、畫面比例（從 36×24 mm 裁切）、橫幅／直幅 |
| 光線 | 日期、台北時間；跳到日出、金色時刻、正午、日落、藍色時刻；太陽與月亮的方位、仰角與月相；雲量、能見度、曝光補償 |
| 顯示與分享 | 樹木開關、構圖輔助線、複製分享連結（所有設定都在 URL hash 裡）、下載畫面 PNG |

取景器上可以拖曳轉動鏡頭、滾輪變焦。鍵盤：W/S 前後、A/D 左右平移、R/F 升降、方向鍵轉向與俯仰、+/- 變焦，按住 Shift 加速。

取景器下方的資訊列會顯示台北 101 的距離、方位、是否入鏡、被遮擋的比例，以及它在畫面中所占的高度。

## 準確度

- **位置**：園區邊界、各建築位置取自 OpenStreetMap（relation 1506269 等），主軸方位 118.3°（牌樓 → 紀念堂），台北 101 以塔身中心經緯度換算，並扣除地球曲率造成的下沉（約 1.2 m）。
- **尺寸**：依中正紀念堂管理處公布的數據：堂高 70 m（台基 14.5 m＋堂身 24 m＋屋頂 31.5 m）、堂身 40 m 見方且四角突出 7.5 m、正面 84 級台階、牌樓高 30 m 寬 80 m（五間六柱十一樓）、民主大道 380 × 40 m、廣場 120 × 120 m。台北 101：屋頂 449.2 m、塔尖 508 m、8 節花瓣每節 8 層。
- **光線**：太陽與月亮位置以 [suncalc](https://github.com/mourner/suncalc) 計算；天空為 Preetham 模型，另補上日落後的暮光與城市夜空光害；霧以能見度（Koschmieder 定律）換算。
- **台北 101 夜間燈光**依星期幾變色（一紅、二橙、三黃、四綠、五藍、六靛、日紫）。

## 已知限制

- **沒有周邊城市建築**。園區外只是平面地面，所以從地面望向 101 時，實際上會被沿途大樓擋住的下半截，在這裡會完整露出。101 的上半部與天際線的相對位置、角度、大小仍然正確。
- 建築是程序化的簡化模型。戲劇院與音樂廳的高度、屋頂比例，以及樹木的位置與密度都是示意。
- 天空、曝光與色調是近似值，適合判斷光線方向與大致氛圍，不代表實際色溫與亮度。

## 程式結構

```
src/
  main.ts              組裝：狀態 → 場景、HUD、鍵盤、渲染迴圈
  state.ts             拍攝設定的狀態管理與 URL hash 編解碼
  lens.ts              焦段 ↔ 視角、畫面比例
  geo.ts               經緯度 ↔ 場景座標（WGS84 局部切平面）
  scene/
    world.ts           場景總成、站立面高度查詢
    cks.ts             中正紀念堂園區（紀念堂、牌樓、戲劇院、音樂廳、大門、圍牆、水池、樹木）
    taipei101.ts       台北 101
    environment.ts     太陽／月亮、天空、陰影、霧、夜間燈光、自動曝光與測光
    geometry.ts        放樣（loft）、中式屋頂、台階、欄杆等建模工具
    materials.ts       材質與程序化貼圖
    trees.ts           樹木（InstancedMesh）
    landmarks.ts       地標經緯度與海拔
  views/
    viewfinder.ts      取景器：渲染、構圖線、目標提示、101 遮擋判定
    mapview.ts         俯視地圖／立體環視
  ui/panel.ts          控制面板
```
