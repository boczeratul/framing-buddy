# Framing Buddy · 取景規劃

攝影師的拍攝規劃工具：選擇世界上任何地點，預覽不同鏡頭焦段、角度、高度與時間光線下的畫面，並確認地標會不會入鏡、會不會被擋住。起始點是台北中正紀念堂自由廣場。

## 啟動

```bash
cp .env.example .env.local   # 填入 Google Maps Platform 金鑰
npm install
npm run dev                  # http://localhost:5173
npm run build                # 型別檢查＋打包到 dist/
```

金鑰需要啟用：Maps JavaScript API、Places API (New)、Map Tiles API（實景 3D 圖磚）。地形高程改用免金鑰的 AWS Terrain Tiles。也可以在介面的「場景載入 → 金鑰」直接貼上金鑰（只存在該瀏覽器）。

> 這是純前端應用，金鑰一定會出現在瀏覽器端。請在 Google Cloud Console 為金鑰設定 **HTTP referrer 限制**（例如 `http://localhost:5173/*` 與正式網域）與 **API 限制**。

沒有金鑰或金鑰無效時會自動改用備援：左側地圖改為俯視圖、近景改用 OpenStreetMap 精細建物、遠景改用 OSM 高樓＋地形。

## 場景如何載入

依相機位置、朝向、視角與可視範圍動態載入，分兩種精細度：

| 範圍 | 有 Google 金鑰時 | 沒有 Google 時（備援） |
| --- | --- | --- |
| **近景**（預設 1 km 內，可調 200 m–3 km） | 有自建精細模型的地標 → **自建模型**，並把該範圍的 Google 模型挖空；其餘 → Google 實景 3D | 自建模型＋ OSM 精細建物（斜屋頂、樹木、綠地、水域） |
| **遠景**（到地平線，約 90 km） | Google Photorealistic 3D Tiles；**顯著的遠山改用自建精細山體** | OSM 高樓（OpenFreeMap 向量圖磚，範圍由「遠景」設定）＋ 地形 |

自建精細模型：

| 地標 | 面數 | 內容 |
| --- | --- | --- |
| 中正紀念堂園區 | 約 100 萬（原約 10 萬） | 琉璃瓦壟與瓦當、垂脊小獸、鴟吻、白色斗拱、內傾角樓、拱門線腳、匾額、御路國徽、細緻欄杆與斜坡扶手、藻井；牌樓五個半圓拱、抱鼓石、「自由廣場」匾；戲劇院／音樂廳紅柱、彩畫、重簷；圍牆八角窗 |
| 台北 101 | 約 10 萬（原約 2,700） | 逐層玻璃帶與樓板凸緣、立面鰭板、四角雙重內凹、如意與雲紋、古錢幣、觀景台欄杆、階梯冠頂、分節塔尖、西北側 L 形商場與玻璃弧形天窗 |
| 哈爾格林姆教堂（雷克雅維克） | 約 5.6 萬 | 依 OSM 126 個建物部件與照片：階梯狀玄武岩柱翼、塔身尖拱入口、細長窗、四面時鐘、百葉鐘樓、小尖塔組成的塔尖、中殿尖拱窗與扶壁、階梯山牆、盔形圓頂後殿；廣場鋸齒鋪面、萊夫·艾瑞克森像、旗杆、**東北草坪上的五座星形鞦韆** |

- 自建模型只在地標進入近景範圍時出現；離開後由 Google 模型呈現。自建模型的底座高度會對齊周圍的 Google 地面。
- 遮擋判定（目標被擋住多少）也會排除已被自建模型取代的 Google 建物。
- 選擇距離原點 2.5 km 以上的地點時，會以新地點為原點重建整個場景，時區也會自動切換。

## 遠山（例如從河口湖、山中湖、忍野八海望向富士山）

- **地形**：AWS Terrain Tiles（Terrarium 編碼的全球 DEM，免金鑰），三圈精細度：±6 km 100 m 網格、±25 km 400 m、±90 km 1.5 km，並扣除地球曲率下沉。Google 模型同樣載入到地平線。
- **山峰目標**：OpenFreeMap 向量圖磚的 `mountain_peak` 圖層，取地平線內最醒目的 12 座（依相對高度／距離排序）。可在「目標」選單對準；資訊列只判斷**山頂天際線**是否被擋。
- **精細山體**：相對高度超過 1400 m 的最醒目山峰（最多 2 座，例如富士山）改用自建模型，並挖掉該範圍的 Google 粗圖磚：
  - DEM z13（約 15 m／像素）建 50–80 m 網格，範圍約為相對高度的 3 倍（上限 12 km），外緣加裙邊蓋住接縫；
  - 依海拔、坡度與**季節雪線**上色（森林、裸露火山礫、積雪；雪線依緯度與月份估算，富士山約 10 月初冠雪、7–8 月無雪）；
  - 頂點著色器沿太陽方向在高度圖上步進，計算**山體自身陰影**；
  - 直射光依山體所在海拔重新計算大氣穿透與地平線下沉：日出時受光面泛紅（赤富士），觀測者日落後山頂仍有餘暉。
- **霧**依高度變化：霾集中在低空（尺度高度 1.4 km），能見度代表相機高度的水平能見度，高山山頂比山腳清楚。預設能見度 25 km（可調到 150 km）。
- 快速位置新增「日本・富士山周邊」：河口湖大石公園、產屋崎、新倉山淺間公園忠靈塔、忍野八海、山中湖長池親水公園與 Panorama 台、本栖湖中之倉峠。

## 測光

取景器使用**多重測光（偏重中央）**，模擬 Sony「多重測光 Multi」：把畫面以線性 HDR 渲染成 48×32 個測光區，
以高斯權重偏重中央、降低畫面上方亮天空的權重、截頂周邊的極亮區（太陽、反光），再以加權對數平均對應 18% 中灰。
逆光時主體保有細節、天空偏亮；夜間結果會限制在合理範圍內，保留夜景感。曝光補償（±3 EV）疊加在測光結果上。

## 介面

左側是**控制區**，右側是**取景結果**。

| 區塊 | 內容 |
| --- | --- |
| 地圖 | Google 地圖：上方搜尋任何地點；點一下移動、拖曳相機或橘色把手、Shift＋點一下朝該點對準；顯示視角扇形、近景（綠）與遠景（白）範圍、太陽／月亮／目標方向線 |
| 俯視／立體 | 以場景本身渲染的俯視圖（含陰影）與繞相機旋轉的 3D 視角（含視錐） |
| 位置 | 快速位置（中正紀念堂各點、哈爾格林姆教堂鞦韆網美角度等、象山、巴黎、東京、紐約、香港）、輸入經緯度、我的位置、東西／南北微調 |
| 高度 | 離站立面的高度；勾選「站在地面／屋頂／台階上」時自動貼合（實景模型也適用），取消則為空拍高度 |
| 方向 | 方位角、俯仰、水平；目標下拉選單（地標、範圍內有名稱的高樓與高塔）＋對準；對準太陽、月亮 |
| 鏡頭 | 全片幅等效焦段 8–1200 mm、畫面比例（從 36×24 mm 裁切）、橫幅／直幅 |
| 光線 | 日期與**拍攝地點當地時間**；跳到日出、金色時刻、正午、日落、藍色時刻；太陽、月亮位置與月相；雲量、能見度、曝光補償 |
| 場景載入 | 遠景範圍、近景半徑、是否使用 Google 實景圖磚、實景模型是否套用模擬日照、載入狀態、金鑰 |
| 顯示與分享 | 構圖輔助線、複製分享連結（地點與所有設定都在 URL 裡）、下載畫面 PNG |

取景器上可以拖曳轉動鏡頭、滾輪變焦。鍵盤：W/S 前後、A/D 左右平移、R/F 升降、方向鍵轉向與俯仰、+/- 變焦，按住 Shift 加速。資訊列顯示目前目標的距離、方位、是否入鏡、被遮擋的比例與在畫面中的高度。

## 準確度與限制

- **實景模型的光影**：Google 圖磚的貼圖本身含拍攝當時的光影；開啟「模擬日照」時會再疊上模擬的太陽方向與陰影，適合判斷光線方向，但原有的陰影不會消失。
- **高度對齊**：實景圖磚使用橢球高，會自動與 DEM 比對校正（圖磚由粗到細載入期間反覆校正）；在陡坡或密集建築區可能有數公尺誤差。
- **Google 實景的近距離樹叢**：在樹林或灌木中（例如忠靈塔觀景台周圍）看起來會很破碎；瞬間移動時相機會站在實景表面上，必要時可調整離地高度。
- **精細山體**只取代最醒目的一兩座山；其他遠山仍是 Google 粗圖磚（照片烘焙光影）。自建山體與 Google 地面在山麓交界處色調可能不同。
- **沒有 Google 時遠景只有高樓**：低於 25 m 的建物不會出現在遠景；遠景建物是依輪廓與高度擠出的方塊。
- 自建模型是依照片與公開資料的程序化重建，細部比例（例如牌樓各拱高度、鞦韆框架尺寸）為目測估算；樹木位置為示意。
- 鞦韆參考：小紅書與 Instagram 需要登入無法直接取得，改以微博、Flickr 與 Wikimedia Commons 的照片及 OSM 資料（way 1382897190，5 座）建模。
- **OSM 資料完整度**因地區而異；近景備援依賴公共 Overpass 伺服器，忙碌時會較慢或失敗（會自動重試、結果快取 14 天）。
- 天空、曝光與色調是近似值，適合判斷光線方向與大致氛圍，不代表實際色溫與亮度。

## 程式結構

```
src/
  main.ts                 組裝：狀態 → 場景、地圖、HUD、鍵盤、渲染迴圈
  state.ts                拍攝設定（含原點經緯度、時區）與 URL hash 編解碼
  geo.ts                  可移動原點的經緯度 ↔ 場景座標
  time.ts                 時區查詢（離線資料表）與當地時間換算
  lens.ts                 焦段 ↔ 視角、畫面比例
  config.ts, google.ts    金鑰與 Maps JavaScript API 載入
  world/
    World.ts              場景總成：近／遠景協調、站立面、遮擋物、目標
    photoreal.ts          Google 實景 3D 圖磚（近景遮罩、地面校正、受光材質）
    terrain.ts            三圈 DEM 地形（到地平線）
    mountains.ts          精細山體（DEM 網格、季節雪線、自身陰影、高海拔日照）
    peaks.ts              山峰目標（向量圖磚 mountain_peak）
    season.ts             雪線、林線估算
    landmarks.ts          地標手工模型圖層（中正紀念堂、台北 101）
    presets.ts            快速位置
    osm/
      OsmLayer.ts         依視野動態載入／釋放圖磚（Google 模式只取有名稱的高樓當目標）
      vectortiles.ts      遠景：OpenFreeMap 向量圖磚
      overpass.ts         Overpass 佇列與 IndexedDB 快取
      parse.ts            OSM 幾何、高度與屋頂標籤
      mesh.ts             程序化建物、屋頂、樹木、綠地
      named.ts            有名稱的高樓與高塔（可對準的目標）
  scene/
    environment.ts        太陽／月亮、天空、陰影、霧、夜間燈光、自動曝光與測光
    ringmask.ts           近／遠景交界的 shader 裁切
    cks.ts, taipei101.ts, hallgrimskirkja.ts  地標精細模型
    nyhavn*.ts            新港：平面資料（scripts/nyhavn/extract.py 產生）、逐棟規格、材質、建模
    regionmask.ts         自建模型接手範圍：挖空 Google 圖磚（畫面、陰影、射線）
    geometry.ts, materials.ts, trees.ts
  views/
    viewfinder.ts         取景器：渲染、構圖線、目標提示、遮擋判定
    metering.ts           多重測光（偏重中央）
    googlemap.ts          Google 地圖面板
    mapview.ts            俯視／立體視圖
  ui/panel.ts             控制面板
```
